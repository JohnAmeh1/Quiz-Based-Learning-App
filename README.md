📘 EduQuest – Quiz-Based Learning & Online Tutoring Platform

Empowering personalized education through interactive quizzes, mentorship, and premium access — all in one place.

🚀 Overview

EduQuest is a full-stack, quiz-based learning and online tutoring platform that bridges the gap between learners and mentors. The platform is built to deliver interactive education through assessments, real-time guidance, and an intuitive dashboard experience.

With EduQuest, students can learn, test their knowledge, and seek help from verified mentors. The platform supports a freemium model, with Paystack integration for seamless payment and upgrade to premium features.

🎯 Key Features

🧑‍🎓 Learner Dashboard: Take quizzes, view scores, track progress, and explore mentorship options.

👨‍🏫 Mentorship System: Mentors sign up via a payment gateway and get listed for students to connect with.

🛠️ Admin Panel: Full access to manage content, monitor users, approve mentors, and update resources.

💳 Paystack Integration: Secure and verified payment system for premium access and mentor onboarding.

📚 Quiz Engine: Topic-based quizzes with instant scoring and analytics.

🔐 Role-Based Access:

Admin: Full read/write control.

Learners: Read-only access to courses and mentors.

Mentors: Access to tutoring requests after successful onboarding.
