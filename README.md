A QUIZ BASED LEARNING AND ONLINE TUTORING PLATFORM (EduQuest)

A full stack quiz based learning and online tutoring platform equipped an admin page, mentorship page and a learners dashboard. The option to pay for the premium version has been setup successfully with the paystack payment gateway. The admin has the right to read and write data while the learner can only read, and those signed up as mentors after paying a fee become teachers of the community and in turn wait to be connected to students in need.
