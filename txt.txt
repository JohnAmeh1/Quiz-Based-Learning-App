Building a **learning app** in PHP and JavaScript with a gamified experience can be a great project for your final year, and it aligns well with your interest in high-impact projects. Here’s how we can structure the app:

### Project Overview
The learning app will have the following features:

1. **User Registration and Login**: Users can sign up and log in to track their progress.
2. **Courses and Modules**: The app will include different courses with a set of modules or topics.
3. **Questions Dataset**: Each course will have a set of questions stored in a database.
4. **Answer Validation and Navigation**:
   - If the user's answer is correct, they proceed to the next question.
   - If the user's answer is wrong, they return to the previous question.
5. **Progress Tracking**: The app will track user progress and only unlock the video section after completing the entire course.
6. **Gamification Elements**: We can add:
   - **Scoreboard and Levels**: Points for each correct answer and leveling up based on performance.
   - **Badges and Achievements**: Award badges for completing modules, perfect scores, etc.
   - **Timer**: Add a timer for each question to increase challenge.
   - **Leaderboard**: Show a leaderboard of top users to add competition.

### Tech Stack
- **Backend**: PHP (for API and server-side logic)
- **Frontend**: HTML, CSS, JavaScript
- **Database**: MySQL (using XAMPP as your local server)
- **Additional Tools**: Bootstrap for UI, AJAX for dynamic updates

## Database Design
### 1. Tables
#### Users Table
```sql
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL,
    password VARCHAR(255) NOT NULL,
    score INT DEFAULT 0,
    level INT DEFAULT 1,
    completed_courses TEXT DEFAULT '[]'
);
```
CREATE TABLE `users` (
  `id` int(11) NOT NULL,
  `username` varchar(30) NOT NULL,
  `email` varchar(100) NOT NULL,
  `password` varchar(255) NOT NULL,
  `date` date DEFAULT NULL,
  `image` varchar(1024) DEFAULT NULL,
  `bio` text DEFAULT NULL,
  `fb` varchar(100) DEFAULT NULL,
  `tw` varchar(100) DEFAULT NULL,
  `yt` varchar(100) DEFAULT NULL
)

#### Courses Table
```sql
CREATE TABLE courses (
    id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(100) NOT NULL,
    description TEXT,
    is_video_unlocked BOOLEAN DEFAULT 0
);
```

#### Questions Table
```sql
CREATE TABLE questions (
    id INT AUTO_INCREMENT PRIMARY KEY,
    course_id INT,
    question TEXT,
    option_a VARCHAR(100),
    option_b VARCHAR(100),
    option_c VARCHAR(100),
    option_d VARCHAR(100),
    correct_option CHAR(1),
    FOREIGN KEY (course_id) REFERENCES courses(id)
);
```

#### User Progress Table
```sql
CREATE TABLE user_progress (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT,
    course_id INT,
    current_question INT DEFAULT 1,
    score INT DEFAULT 0,
    completed BOOLEAN DEFAULT 0,
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (course_id) REFERENCES courses(id)
);
```

## Backend API (PHP)
### 1. User Login (login.php)
```php
<?php
session_start();
include 'db.php';

$username = $_POST['username'];
$password = $_POST['password'];

$query = "SELECT * FROM users WHERE username='$username'";
$result = mysqli_query($conn, $query);
$user = mysqli_fetch_assoc($result);

if ($user && password_verify($password, $user['password'])) {
    $_SESSION['user_id'] = $user['id'];
    echo json_encode(['status' => 'success']);
} else {
    echo json_encode(['status' => 'error', 'message' => 'Invalid credentials']);
}
?>
```

### 2. Fetch Question (fetch_question.php)
```php
<?php
session_start();
include 'db.php';

$user_id = $_SESSION['user_id'];
$course_id = $_POST['course_id'];

$query = "SELECT * FROM user_progress WHERE user_id='$user_id' AND course_id='$course_id'";
$result = mysqli_query($conn, $query);
$progress = mysqli_fetch_assoc($result);

$current_question = $progress['current_question'];

$question_query = "SELECT * FROM questions WHERE course_id='$course_id' AND id='$current_question'";
$question_result = mysqli_query($conn, $question_query);
$question = mysqli_fetch_assoc($question_result);

echo json_encode($question);
?>
```

### 3. Submit Answer (submit_answer.php)
```php
<?php
session_start();
include 'db.php';

$user_id = $_SESSION['user_id'];
$course_id = $_POST['course_id'];
$answer = $_POST['answer'];

$query = "SELECT * FROM user_progress WHERE user_id='$user_id' AND course_id='$course_id'";
$result = mysqli_query($conn, $query);
$progress = mysqli_fetch_assoc($result);

$current_question = $progress['current_question'];

$question_query = "SELECT * FROM questions WHERE course_id='$course_id' AND id='$current_question'";
$question_result = mysqli_query($conn, $question_query);
$question = mysqli_fetch_assoc($question_result);

if ($question['correct_option'] === strtoupper($answer)) {
    // Correct answer, move to next question
    $next_question = $current_question + 1;
    $update_query = "UPDATE user_progress SET current_question='$next_question', score=score+10 WHERE user_id='$user_id' AND course_id='$course_id'";
    mysqli_query($conn, $update_query);
    echo json_encode(['status' => 'correct']);
} else {
    // Wrong answer, go back to previous question
    $prev_question = max($current_question - 1, 1);
    $update_query = "UPDATE user_progress SET current_question='$prev_question' WHERE user_id='$user_id' AND course_id='$course_id'";
    mysqli_query($conn, $update_query);
    echo json_encode(['status' => 'incorrect']);
}
?>
```

### JavaScript (app.js)
```js
function fetchQuestion(courseId) {
    $.post('fetch_question.php', { course_id: courseId }, function(data) {
        const question = JSON.parse(data);
        $('#question-text').text(question.question);
        $('#option-a').text(question.option_a);
        $('#option-b').text(question.option_b);
        $('#option-c').text(question.option_c);
        $('#option-d').text(question.option_d);
    });
}

function submitAnswer(answer) {
    const courseId = 1; // Example course ID
    $.post('submit_answer.php', { course_id: courseId, answer: answer }, function(data) {
        const response = JSON.parse(data);
        if (response.status === 'correct') {
            alert('Correct! Moving to next question.');
            fetchQuestion(courseId);
        } else {
            alert('Incorrect! Returning to previous question.');
            fetchQuestion(courseId);
        }
    });
}
```
